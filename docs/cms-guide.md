# Guide CMS SOGICA

## Accès

`/admin` — connexion avec rôle approprié.

## Rôles

| Rôle | Usage |
|------|-------|
| super-admin | Users, CSS avancé, settings sensibles |
| admin | Contenu + thème (sans CSS avancé) |
| editor | Pages, expertises, clients, équipements |
| portfolio-manager | Projets + médias |

## Page builder

Pages → éditer → blocs :

- Ajouter / supprimer / réordonner / dupliquer / masquer
- 20+ blocs (Hero, Galerie, Grille expertises, CTA, etc.)
- Preview via versions brouillon

## Médias

- Import WhatsApp : statut **Non assigné**
- Bulk assign : champ Projet sur chaque média
- Alt localisé obligatoire pour contenu informatif
- Dossiers virtuels : organisation technique seulement

## Réalisations

**Ne créer un projet que si un document source l'atteste.**

Champs optionnels : client, dates, lieu, coordonnées GPS.

Mode éditorial : blocs narratifs libres.

## Thème

Paramètres → Thème & design : couleurs, typo, espacement, motion.

Super Admin : CSS avancé (pas de JS).

## Formulaires

Formulaires → soumissions contact/devis avec workflow statut.
